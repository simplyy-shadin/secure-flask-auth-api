# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Send a private
report to the repository owner through GitHub's private vulnerability reporting
feature when available.

Include the affected endpoint, reproduction steps, expected impact, and relevant
request/response details. Do not include real credentials, access tokens, or
third-party personal data.

## Scope

This repository is an educational security-engineering project focused on
authentication and API security. It is not offered as a hosted production
identity provider.
